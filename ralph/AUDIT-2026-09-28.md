# ARIA audit and repair — 2026-09-28

Baseline: `main` at `b964c71`. Changes remain local and uncommitted; no release or tag was published.

## Confirmed defects repaired

- **Reply isolation:** each submission interrupts prior playback and detaches the previous assistant bubble and text/TTS buffers. A superseded screen capture cannot submit a late request.
- **Session isolation:** barge-in/new/resumed sessions invalidate pending voice transcription, stop active capture, clear VAD/timers and reject late partial/final/failure events.
- **Microphone recovery:** listening retries single-flight microphone acquisition after failure and does not open STT without a microphone. Releasing push-to-talk or changing sessions while permission acquisition is pending cancels the pending utterance.
- **Voice/model provisioning:** STT/TTS lazy starts and live restarts provision selected assets first; unsuccessful provisioning prevents launch. Focused tests mock provisioning rather than downloading additional voice models.
- **SSE termination:** `[DONE]` settles immediately even if the server leaves HTTP open; subsequent tokens are ignored and completion occurs once.
- **SSE provider errors:** errors carried within HTTP-200 event streams surface as failures rather than empty successful replies.
- **Model discovery:** top-level JSON arrays are accepted and deduplicated; incremental UTF-8 decoding preserves model names split across network chunks.
- **Electron security and compatibility:** upgraded locked Electron 40.10.6 to exact 42.11.8, with Node >=22.12.0 and explicit binary installation in release CI. The audit gate now includes Electron/build dependencies instead of excluding dev dependencies.
- **Release publication:** native build jobs no longer race to publish the same tag. One dependent finalizer assembles platform artifacts and merged macOS update metadata, uploads them and publishes. Artifact collection retains `latest*.yml` and blockmaps but excludes builder debug YAML. Release concurrency and write permissions are scoped.

## Limitations and remaining acceptance gates

- No complete installer build/install test, signed macOS test, Windows runtime test or hosted release-workflow execution was performed. Do not ship the package-directory artifact as a complete voice distribution without staging Whisper and verifying frozen sidecars.
- Renderer regressions execute production functions under deterministic DOM/IPC/media mocks. Real device permission/reconnection and manual overlapping-conversation UI testing remain distinct acceptance checks; Electron boot/IPC tests are not substitutes for them.
- Live switching to previously absent Kokoro/Piper downloads is covered at the provisioning boundary, not by an end-to-end new-model download.
- Latency is close to the configured threshold on this machine and needs representative-host measurement; the threshold was not relaxed to manufacture a pass.
- This is a focused code/dependency audit, not a proof of absence of all defects. One read-only renderer reviewer returned the confirmed UI findings; the separate sidecar reviewer was interrupted. No final independent review of the complete repaired tree was obtained.
